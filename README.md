# نرخ‌نما

یک داشبورد راست‌به‌چپ برای مشاهده نرخ مرجع ارز، برآورد طلای ۱۸ عیار، تبدیل ارز و جستجوی صرافی حضوری؛ با PHP و JavaScript ساده و بدون فریم‌ورک.

## اجرا

به PHP 7.4 یا جدیدتر با `allow_url_fopen` و پشتیبانی HTTPS (افزونه OpenSSL) نیاز دارید:

```bash
php -S 0.0.0.0:8000
```

سپس آدرس `http://localhost:8000` را باز کنید. پوشه پروژه را می‌توان روی هر هاست PHP با دسترسی خروجی HTTPS قرار داد. پوشه موقت سیستم باید برای PHP قابل نوشتن باشد تا کش عمل کند. در صورت عدم دسترسی به منابع، سایت به جای ساختن قیمت، خطا یا آخرین داده کش‌شده را نشان می‌دهد.

## منابع و محدودیت‌ها

- نرخ USD و EUR از [ExchangeRate-API Open Access](https://open.er-api.com/v6/latest/USD) دریافت می‌شود. IRR بر ۱۰ تقسیم می‌شود تا به تومان تبدیل شود. **این نرخ مرجع است، نه نرخ بازار آزاد ایران.**
- قیمت اونس طلا از [Gold API](https://api.gold-api.com/price/XAU) دریافت می‌شود. قیمت تخمینی هر گرم طلای ۱۸ عیار = قیمت اونس دلاری ÷ ۳۱٫۱۰۳۴۷۶۸ × ۰٫۷۵ × نرخ مرجع دلار به تومان؛ اجرت، مالیات و اختلاف بازار در آن لحاظ نشده است.
- داده‌ها حداکثر هر پنج دقیقه از سمت سرور دوباره درخواست می‌شوند؛ زمان واقعی به‌روزرسانی هر منبع ممکن است متفاوت باشد. در صورت شکست درخواست، آخرین کش موفق پس از ۱۰ دقیقه به عنوان داده ذخیره‌شده مشخص می‌شود.
- جستجوی صرافی به Google Maps هدایت می‌شود و تأیید مجوز نیست. پیش از مراجعه، اعتبار مجوز و اطلاعات صرافی را از بانک مرکزی بررسی کنید.
- GitHub Pages کد PHP را اجرا نمی‌کند. برای انتشار وب‌سایت به هاست PHP نیاز است؛ قرار دادن کد در GitHub به تنهایی به معنی اجرای سایت نیست.

## پیش‌نمایش GitHub Pages

`index.html` نسخه ایستای رابط برای GitHub Pages است و نرخ‌ها را مستقیماً از مرورگر و همان منابع عمومی دریافت می‌کند؛ دسترسی مرورگر به آن منابع ضروری است. در این حالت کش PHP وجود ندارد و در صورت شکست درخواست، خطا نمایش داده می‌شود. GitHub Pages خود PHP را اجرا نمی‌کند. برای استفاده از API سمت سرور، پروژه را روی هاست PHP اجرا کنید و مستقیماً `index.php` را باز کنید (یا `index.php` را به عنوان فایل پیش‌فرض سرور تنظیم کنید).
